## 0.7.0 · Build 7 · August 2026
- 🇬🇧 **Ways to block** explained in the app (SelfGuard filter, Android private DNS, home network filter — each with real downsides); an active filtering **private DNS is detected**. 89 unit tests.
- 🇩🇪 **Wege zum Blocken** in der App erklärt (Filter von SelfGuard, privates DNS von Android, Filter im Heimnetz — jeweils mit echten Nachteilen); ein schon filterndes **privates DNS wird erkannt**. 89 Unit-Tests.

## 0.6.0 · August 2026
- 🇬🇧 **Uninstall fixed** (missing `REQUEST_DELETE_PACKAGES`, wrong intent flag made the queue run through without waiting); real umlauts throughout the project. 86 unit tests.
- 🇩🇪 **Deinstallation repariert** (fehlendes `REQUEST_DELETE_PACKAGES`, falsches Intent-Flag ließ die Warteschlange ohne Warten durchlaufen); echte Umlaute im ganzen Projekt. 86 Unit-Tests.

## 0.5.0 · August 2026 🔒
- 🇬🇧 First release: checksum check, **stalkerware detection** (Echap, CC-BY 4.0), permission profiles, hidden apps, brand fakes, device checks; **local DNS filter** with HaGeZi lists; clean-up actions. Includes the security review of 18 Aug 2026 (DNS spoofing fix, worker rate limit, https only). 86 unit tests, release APK 1.9 MB.
- 🇩🇪 Erste Version: Prüfsummenabgleich, **Stalkerware-Erkennung** (Echap, CC-BY 4.0), Berechtigungsprofile, versteckte Apps, Markenfälschungen, Geräteprüfungen; **lokaler DNS-Filter** mit HaGeZi-Listen; Aufräum-Aktionen. Enthält die Sicherheitsprüfung vom 18.08.2026 (Schutz gegen untergeschobene DNS-Antworten, Durchsatzbegrenzung im Worker, nur https). 86 Unit-Tests, Release-APK 1,9 MB.
